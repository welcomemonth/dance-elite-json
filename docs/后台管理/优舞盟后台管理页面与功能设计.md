# 优舞盟 PC 后台管理端 — 页面与功能设计（不含 UI 视觉）

> 依据：《优舞盟报名功能.md》（2.8 后台管理流程、订单状态机、退款/候补规则）、《国舞菁英独舞冠军赛FAQ.md》（赛制/榜单/积分/奖金规则）、《优舞盟小程序页面与功能设计.md》（小程序端页面与状态，后台为其管理端）。
> 本文只描述**页面结构、功能点、按钮与管理员操作流**，不涉及颜色、样式等视觉设计。
> 榜单/积分模块与报名系统在**数据上无关联**，后台亦按两个独立模块设计，仅共用账号体系与主框架。

---

## 0. 全局结构、角色与权限

### 0.1 整体框架

- **登录页**：账号 + 密码登录（后台账号由系统管理员创建，不走微信登录）。
- **主框架**（登录后所有页面共用）：
  - **左侧导航栏**：一级菜单分组展示（见 0.3），当前菜单高亮；二级页面不进入导航。
  - **顶部栏**：面包屑（当前位置）、当前登录人姓名与角色、退出登录。
  - **内容区**：页面标题 + 操作区 + 内容。
- **通用列表页布局**（全站统一）：
  1. 筛选区（下拉/日期范围/关键字搜索，关键字支持姓名、脱敏证件号、订单号、手机号）。
  2. 操作行（左侧：批量/导出类操作；右侧：「新建」类主操作按钮）。
  3. 数据表格（分页；金额、时间字段格式化；空态文案「暂无数据」）。
  4. 行内操作列（查看/编辑/处理等，按状态显隐）。
- **通用详情页布局**：上部「描述列表」（分组展示只读信息）+ 下部「操作区」（主/次按钮）。
- **通用交互规范**：
  - 所有**危险/不可逆操作**（发布赛事、下架、关闭组别、退款、移出候补、删除成绩）必须二次确认弹窗。
  - 身份证号、手机号默认脱敏展示（138****5678、1101**********1234）；**明文查看需单独权限且全程留日志**（谁、何时、看了谁的）。
  - 所有关键写操作留**操作日志**（操作人、时间、内容、前后值）。

### 0.2 角色与权限矩阵

| 功能模块 | 管理员 | 客服 |
|---|---|---|
| 数据看板 | 全量 | 仅待办工单相关 |
| 赛事管理（创建/发布/名额/关闭组别） | ✅ | ❌ |
| 订单查询与导出 | ✅ | 只读（不可导出证件号明文） |
| 退款处理（同意/驳回） | ✅ | ❌（仅可登记工单） |
| 人工报名（无身份证号选手） | ✅ | ❌（仅可登记工单） |
| 候补管理 | ✅ | 只读 |
| 资料催收与导出 | ✅ | 只读 |
| 榜单/积分/成绩/奖金 | ✅ | ❌ |
| 内容管理 | ✅ | ❌ |
| 客服工单 | ✅（处理） | ✅（登记、查看自己登记的） |
| 系统管理（账号/日志） | ✅ | ❌ |

> 客服的登记动作也可发生在微信原生客服会话中，后台的「客服工单」模块负责承接与流转这些登记（见 11 节）。

## 1. 数据看板（登录后首页）

**页面布局（自上而下）：**

1. **核心指标卡片区**（数字卡，点击可跳对应列表）：
   - 今日新增有效报名（笔数、金额）
   - 累计有效报名 / 累计实收金额
   - 待处理退款工单（角标，>0 时突出）
   - 候补中人数（全赛事合计）
   - 未传齐资料报名数
   - 进行中赛事数（报名中 N 场 / 待开赛 N 场）
2. **待办事项列表**（两列）：
   - 左列「待我处理」：退款工单、客服新登记、临近截止赛事（如「X 赛事 2 天后截止报名」）。
   - 右列「报名监控」：各进行中赛事的组别报名进度条（已报/名额，满员标红、含候补人数）。
3. **趋势图表区**：
   - 近 30 日报名/支付金额趋势（按日）。
   - 可切换赛事查看该赛事的报名走势。
4. **快捷操作区**：「创建赛事」「导出名单」「处理退款」按钮。

**管理员操作：**

| 操作 | 结果 |
|---|---|
| 点击指标卡 / 待办项 | 跳转对应模块并带筛选条件 |
| 点击快捷操作 | 跳转对应功能页 |

## 2. 赛事管理

### 2.1 赛事列表

**表格列：** 赛事名称、级别（甲级赛/超级赛/年度总决赛）、举办城市、比赛日期、报名费、状态、报名进度（各组别合计「已报/名额」）、操作。

**状态枚举：** 草稿 → 未发布 → 报名中 → 报名截止 → 比赛中 → 已结束；另有手动「已下架」（小程序端不可见）。

**筛选：** 状态、级别、赛季/年份、关键字。

**操作：**

| 按钮 | 适用状态 | 结果 |
|---|---|---|
| 新建赛事 | — | 进入创建表单 |
| 编辑 | 草稿/未发布 | 进入编辑表单 |
| 发布 | 未发布 | 二次确认 → 小程序端立即可见；校验时间线与名额必填 |
| 下架 | 报名中/未开始 | 二次确认（提示：小程序端立即不可见/不可报，已支付报名不受影响） |
| 查看详情 | 全部 | 进入赛事详情页 |
| 复制新建 | 全部 | 以该赛事为模板预填创建表单 |

### 2.2 创建 / 编辑赛事

**表单分区：**

1. **基本信息**
   - 赛事名称（必填）、级别（甲级赛/超级赛/年度总决赛，单选必填）。
   - 举办城市、比赛地点、比赛日期（必填）。
   - 报名费（必填，总决赛默认为 0/免费）。
   - 封面图（选填，用于小程序详情页头图）。
2. **赛事时间线**（5 个节点，均为日期时间选择器，强制先后逻辑校验）：
   - 报名开始 → 截止报名 → 抽签 → 核对舞蹈音频（= 资料上传最终期限）→ 开始比赛。
   - 校验：任一节点须晚于前节点；保存时提示「截止报名后不可再报名/退款」。
3. **组别配置**
   - U11 / U13 / U15 三个组别，各含：开关、名额数（必填正整数）。
   - 出生年份范围（U11 2016–2018、U13 2014–2015、U15 2012–2013，截止日 2027-01-01）为**系统规则只读展示**，不可修改。
4. **规则与说明文案**
   - 退费政策（默认模板：抽签前可无偿退；抽签后个人原因退扣 50%；伤病凭医院诊断证明顺延不扣费；原路退回）。
   - 作品时长要求（默认 ≤3 分钟）。
   - 比赛流程说明（常规赛 → 20% 晋级决赛 → 决赛 → 当天颁奖）。
   - 荣誉与奖金说明（默认模板，可按本场赛事调整）。
5. **底部操作**：「保存草稿」「保存并发布」；编辑态另加「取消」。

**已发布赛事的编辑限制：**
- 时间线、级别：不可修改（避免与已产生订单冲突）；如确需变更须走「下架 + 新建」。
- 名额：**只能增加**，不得小于该组别当前已支付人数；增加即时生效（小程序端剩余名额刷新）。
- 组别开关：可单独「关闭组别」（见 2.3）。

### 2.3 赛事详情页（管理视角）

**顶部信息区**：基本信息 + 时间线（已过节点置灰）+ 发布状态。

**Tab 页：**

| Tab | 内容 |
|---|---|
| 报名概览 | 每个组别 × 舞种矩阵：名额/已支付/剩余/候补中；进度条；「加名额」「关闭组别」按钮 |
| 报名名单 | 该赛事全部有效报名（跳转订单管理并自带筛选） |
| 候补队列 | 该赛事候补列表（跳转候补管理并自带筛选） |
| 资料完成度 | 每条报名的资料项完成状态汇总（跳转资料催收） |
| 退款记录 | 该赛事全部退款工单与退款流水 |
| 成绩 | 该赛事成绩录入入口（见 9.2，仅作入口） |

**关键操作：**

- **加名额**：选择组别 → 输入新增数量 → 二次确认 → 即时生效。
- **关闭组别**：选择组别（可具体到舞种维度）→ 二次确认（文案提示「小程序端该组别立即不可报名，已支付报名不受影响」）→ 详情页与报名按钮即时置灰。
- **重新开放组别**：对已关闭组别可恢复（名额不变）。

## 3. 订单中心

### 3.1 订单管理

> 订单 = 选手 × 赛事 × 组别 × 舞种，全量落库：已支付 / 已取消 / 退款处理中 / 已退款（不存在「待支付」状态，见小程序设计 3.2）。

**筛选区：** 赛事（下拉）、组别、舞种、订单状态、来源（小程序/后台人工）、支付时间范围、关键字（选手姓名 / 证件号 / 订单号 / 微信支付单号）。

**默认规则：** 不展示「已取消」订单；勾选「显示已取消（对账）」后才出现，且该状态下表格水印或标注「留档」。

**表格列：** 订单号、赛事、选手姓名、证件号（脱敏）、组别、舞种、金额、状态、来源、支付时间、创建时间、操作（查看详情）。

**操作行：**
- 「导出」：按当前筛选导出 Excel（可选列：含/不含明文证件号；含明文需解密权限并留日志）。
- 批量导出用于对账、签到表制作。

**订单状态与允许操作：**

| 状态 | 行内可用操作 |
|---|---|
| 已支付 | 查看详情、发起退款（跳转退款处理） |
| 退款处理中 | 查看详情（处理入口在退款工单） |
| 已退款 | 查看详情 |
| 已取消 | 仅查看（留档只读，不可任何修改） |

### 3.2 订单详情页

**描述列表分组：**

1. **报名信息**：赛事/级别/组别/舞种、选手姓名、证件号（脱敏，「明文查看」按钮需权限+日志）、机构、联系电话。
2. **支付信息**：订单号、微信支付单号、金额、支付时间、退款流水（时间、金额、单号、处理人）。
3. **资料信息**：资料项清单（证件照缩略图可预览、音频可在线试听/下载、文本项全文），每项标注已传/未传与最后修改时间；超过「核对舞蹈音频」时间后整体只读标注「资料已截止」。
4. **操作记录**：状态流转历史（创建/支付成功/退款申请/退款完成等，含时间与触发方）。
5. **备注**：管理员备注（增删改，留痕）。

**操作区**：
- 「发起退款」（已支付状态，→ 退款工单处理页）。
- 「联系记录」：登记与用户的电话沟通（用于催收、候补、退款协商的留痕）。

## 4. 退款工单

> 小程序端无自助退款入口；用户联系客服 → 客服登记 → 管理员后台人工处理（同意=原路退回 / 驳回=回退为已支付）。

### 4.1 工单列表

**表格列：** 工单号、关联订单号、赛事、选手姓名、登记来源（客服会话/电话/其他）、诉求摘要、登记时间、状态（待处理/已同意/已驳回/退款失败）、处理人、操作。

**筛选：** 状态、赛事、登记时间范围、关键字。

### 4.2 工单处理页

**布局：左摘要 + 右处理区。**

- 左侧：工单信息（客服登记内容原文、用户诉求、登记时间）+ 关联订单摘要（点击可跳订单详情）。
- 右侧处理区：
  - 退费政策提示条（按订单赛事时间线自动判断当前所处阶段）：
    - 抽签前：「可无偿退赛，全额原路退回」。
    - 抽签后：「个人原因退赛扣除 50%；伤病凭医院诊断证明可顺延不扣费」。
  - 退款金额（默认按政策自动填充，允许管理员按实际情况调整，需填调整原因）。
  - 「同意退款」：二次确认（金额、订单、选手）→ 调微信支付退款 API 原路退回。
    - 成功：订单状态 → 已退款；工单 → 已同意；名额即时释放（→ 触发候补提醒，见 6）。
    - 失败：工单 → 退款失败，可查看失败原因并重试。
  - 「驳回」：必填驳回原因 → 订单状态回退「已支付」→ 客服会话告知用户。
  - 处理全程记录处理人、时间、金额、原因（操作日志）。

## 5. 人工报名（特殊通道）

> 用于无中国大陆身份证号的选手（国际友人等）：客服登记 → 管理员后台人工创建报名，不产生在线支付。

### 5.1 人工报名列表

- 与订单同库展示，来源 = 「后台人工」；支持按赛事、状态筛选。
- 行内操作：查看详情、编辑（仅资料未截止前可改报名信息）。

### 5.2 新建人工报名

**表单字段：**

| 字段 | 必填 | 说明 |
|---|---|---|
| 赛事 | 是 | 下拉（限报名中/未开始的赛事） |
| 组别 | 是 | **手选** U11/U13/U15（此通道不受身份证自动判定，需人工确认年龄符合） |
| 舞种 | 是 | 古典舞 / 民族民间舞 |
| 选手姓名 | 是 | — |
| 证件类型 | 是 | 护照 / 港澳台证件 / 其他 |
| 证件号 | 是 | 加密存储；不与大陆身份证判重库混用 |
| 国籍/地区 | 否 | — |
| 机构名称 | 否 | — |
| 联系电话 | 是 | 用于候补通知/赛事联系 |
| 收费方式 | 是 | 线下已收款 / 免费（总决赛、赠票等） |
| 金额 | 随收费方式 | 免费=0 |
| 关联客服工单 | 否 | 关联登记的工单号 |
| 备注 | 否 | 特殊情况说明 |

**提交规则：**
- 名额校验与小程序一致：满员时提示，可改报其他组别或先登记候补。
- 订单状态直接为「已支付」，支付信息标注「后台人工录入」+ 操作人。
- 提交后进入该赛事正常报名名单，资料上传、催收、成绩录入与小程序报名同等对待。

## 6. 候补管理

### 6.1 候补列表

**视图：** 按 赛事 + 组别 + 舞种 分组展示队列，队列内按提交时间先后排序并显示**序号**（通知顺序依据）。

**表格列：** 序号、选手姓名、证件号（脱敏）、机构、联系电话、提交时间、状态、操作。

**状态枚举：** 候补中 → 已通知（管理员已电话联系）→ 已转报名（用户完成正常报名支付）/ 已放弃；用户侧可自助「取消候补」（→ 已取消）。

**筛选：** 赛事、组别、舞种、状态。

### 6.2 队列操作

| 操作 | 说明 |
|---|---|
| 标记「已通知」 | 管理员电话联系后标记，填通知结果备注（确认有意向/待回复/无法接通）；仅操作队首若干条 |
| 确认转报名 | 用户在小程序完成支付后，系统自动将候补记录置「已转报名」并与订单关联；管理员也可手动关联 |
| 移出队列 | 用户放弃 / 多次联系不上 / 不符合条件；二次确认；仅移出队列，不涉及退款 |
| 导出 | 导出当前队列（含电话）用于线下电话通知 |

**名额释放提醒：** 发生退款/关闭组别释放出名额时，对应队列顶部出现提示条「该组别已释放 N 个名额，请按序号电话联系候补者」；名额在小程序端直接变为可报（先到先得），候补仅作兜底。

## 7. 资料催收

### 7.1 未传齐名单

- **筛选：** 赛事、组别、舞种、缺失资料项（证件照/音频/节目名称/电话…）、截止状态（未截止/已截止）。
- **表格列：** 赛事、选手姓名、组别+舞种、联系电话、已传项/总项、缺失项明细、资料截止时间、最后上传时间、操作（查看报名详情、标记已联系）。

### 7.2 操作

- **查看**：跳订单详情的资料区（可预览证件照、试听音频、查看文本）。
- **导出催收名单**：Excel，含联系电话与缺失项，供人工催收（电话/微信）使用。
- **标记已联系**：记录催收时间与备注，避免重复催。
- 到达「核对舞蹈音频」截止时间后，名单自动锁定为只读（与小程序端资料只读同步）。

## 8. 榜单中心（独立模块）

> 与报名系统**无数据关联**：名单导入仅作录入辅助，成绩与积分独立存储、独立发布。小程序端排行榜为只读展示，数据全部来自本模块。

### 8.1 赛季管理

- 赛季列表：名称（如「2026 赛季」）、起止时间、状态（未开始/进行中/已归档）。
- 新建/编辑赛季：名称、起止日期、适用组别规则（默认 U11/U13/U15 + 古典舞/民族民间舞 = 6 榜单）。
- 归档赛季：榜单冻结为历史，小程序端可切换查看。

### 8.2 成绩录入

**步骤流（向导式三步）：**

1. **选择赛事与榜单**：选择赛季下的赛事 → 选择 6 个榜单之一（如「U13·古典舞」）。
2. **导入/录入成绩**（两种方式，可混用）：
   - **【主要方式】上传成绩 Excel**：管理员上传**固定格式**的成绩表格（模板由后台提供下载），系统解析后按**选手证件号（大陆身份证号或护照等其他证件号）为唯一键**自动匹配选手：
     - 匹配成功 → 自动带出选手信息，管理员核对奖项列后确认导入。
     - 匹配失败（证件号未登记过）→ 逐行提示，支持手动指定/新建选手档案后再确认。
     - 导入前展示解析预览（总行数、匹配成功/失败数），确认后才正式写入。
     - 具体 Excel 列格式**待定**（v1 约定：必含证件号列、奖项列；其余列以后续提供的模板为准）。
   - 【辅助方式】在线表格逐行录入：选手从名单中搜索选择（可手动添加）、奖项下拉（冠军/亚军/季军/菁英舞者/特金奖/金奖/银奖）、是否晋级决赛、备注。
   - 用于导入前的选手名单来源：该赛事该榜单的报名名单**仅作搜索辅助**，与榜单数据无关联；无报名记录的手动添加选手以证件号建档。
3. **确认发布**：预览积分计算结果（见 8.3）→ 二次确认发布。发布后该榜单小程序端即时更新；**已发布成绩的修改走「纠错」流程**（见 8.3），全程留痕。

**同一场赛事 6 个榜单需分别录入；每天只比一个舞种，实际每场只需 3 个榜单。**

### 8.3 积分与榜单

- **积分规则配置**（赛季级，默认按 FAQ 规则，可调整）：
  - 名次基础分表（冠军/亚军/季军/各奖项对应分值）。
  - 级别权重：同等奖项下超级赛积分高于甲级赛。
  - 人数系数：积分按名次和参赛人数动态计算（如按榜单参赛人数分档）。
- **榜单计算**：
  - 每名选手取本年度积分最高的 3 场（不足 3 场按实际计）。
  - 每场成绩发布后实时重算并更新小程序端榜单。
- **榜单管理页**：6 个榜单页签切换，展示当前榜单（排名/选手/机构/总积分/场次），支持：
  - 选手展示名设置（真名 / 化名 / 编号）。
  - 隐藏/恢复某选手上榜（二次确认，留痕）。
  - 成绩纠错：修改已发布成绩 → 自动重算积分与排名 → 弹窗预览差异 → 确认生效。
- **榜单说明文案**：维护小程序端「积分规则说明页」的展示内容（纯文本，可预览）。

### 8.4 晋级管理

- **直通卡**：按 FAQ 规则自动标记——甲级赛每个榜单第 1 名、超级赛每个榜单前 2 名 → 总决赛直通；支持管理员手动增补/取消直通卡（需填原因）。
- **积分榜晋级**：每个榜单按全年积分实时排名，前 20 名（扣除直通卡选手后顺延）自动生成「总决赛资格名单」。
- **总决赛名单**：合并直通卡 + 积分晋级，支持手动调整（增补/移除，留痕）→ 导出（用于总决赛组织）→ 发布到小程序端（总决赛选手可查看自己的资格状态，可选）。

### 8.5 机构年度榜

- **机构积分规则配置**：默认机构年度总积分 = 旗下选手年度积分之和（可按需配置上榜数加权等）。
- **榜单页**：年度总积分排名前 10（或全部）机构：排名、机构名称、年度总积分、旗下上榜选手数。
- 荣誉自动标注：第 1–3 名「年度菁英机构奖」+ 10000 元奖金；第 4–10 名「年度十佳机构奖」。
- 发布/更新到小程序端「机构年度榜」页。

### 8.6 奖金管理

- **奖金规则配置**（赛季级，默认按 FAQ）：
  - 甲级赛：每个榜单第 1 名，参赛人数 ≥40 发 2000 元、<40 发 1000 元。
  - 超级赛：每个榜单前 2 名，≥40 发 3000/1500、<40 发 2000/1000。
  - 总决赛：每个榜单前 8 名：10000 / 3000 / 2000 / 1000×5。
  - 机构：年度总积分前 3 名各 10000 元。
- **奖金核算**：每场赛事成绩发布后自动生成奖金明细单（选手/奖项/金额/赛事），支持人工微调（留痕）。
- **发放登记**：现场发放后登记「已发放」（发放日期、领取人/代领人、备注）；支持导出发放表（财务对账）。
- 7 月巅峰赛等特殊场次可标记「不参与上述发放规则」。

## 9. 用户与内容

### 9.1 选手 / 用户管理

- **用户列表**（微信维度）：微信昵称、绑定手机号（脱敏）、报名次数、注册时间、最近活跃。
- **选手档案**（证件号维度聚合）：以**证件号（大陆身份证号或护照等其他证件号）为唯一键**聚合——姓名、机构、历史报名记录（跨微信）、历史成绩与积分汇总。
  - 同一选手多微信报名：系统按证件号判重提示，管理员可手动「合并档案」查看（不合并账号本身）。
- 明文查看证件号/手机号需权限并全程留日志。

### 9.2 内容管理

- **积分规则说明**：维护小程序端 4.4 规则说明页文案（纯文本，支持预览）。
- **赛事规则/FAQ**：维护「关于优舞盟 / 赛事规则说明」页内容。
- **公众号配置**：上传/更换公众号二维码图片与提示文案（小程序端 5.5 展示）。
- **公告（可选）**：小程序端公告位文案与上下线时间。

### 9.3 客服工单

- **登记**：客服（或管理员代录）创建工单：类型（退款诉求 / 无身份证号报名登记 / 候补咨询 / 其他）、用户标识（微信昵称/姓名/手机号）、诉求内容、关联订单（可选）。
- **流转**：待处理 → 处理中 → 已完成（可关联退款工单/人工报名记录）；支持跟进备注。
- **列表**：按状态/类型/时间筛选；超 24 小时未处理标红提醒。

## 10. 系统管理

- **账号与权限**：管理员/客服账号的创建、停用、重置密码；角色权限配置（0.2 矩阵的可配置化）。
- **操作日志**：全站查询——登录、明文查看、退款、名额调整、关闭组别、成绩修改、榜单发布等；按操作人/模块/时间筛选，不可删除。

## 11. 关键后台操作流汇总

| 场景 | 后台操作流 |
|---|---|
| 开放一场赛事 | 赛事管理 → 新建赛事（基本信息+时间线+组别名额+规则文案）→ 保存并发布 → 小程序端可见 |
| 监控报名 | 数据看板 / 赛事详情-报名概览（组别×舞种矩阵） |
| 名额报满 | 自动引导用户候补；管理员在候补管理按序号电话通知 |
| 用户退款 | 客服登记工单 → 退款工单 → 核 policy → 同意（原路退回，订单→已退款，名额释放）或驳回（订单回退已支付） |
| 退赛后补位 | 退款成功释放名额 → 候补队列顶部提醒 → 电话联系队首 → 用户小程序重新报名支付 → 候补标记「已转报名」 |
| 无身份证号选手报名 | 客服登记 → 人工报名 → 新建（手选组别/证件类型/收费方式）→ 进入正常名单 |
| 资料催收 | 资料催收 → 筛选未传齐名单 → 导出（含电话）→ 电话催收 → 标记已联系；截止后自动锁定 |
| 赛后出榜 | 成绩录入（选赛事+榜单 → 上传固定格式成绩 Excel，按证件号/护照号唯一匹配 → 核对确认发布）→ 积分自动重算 → 小程序榜单实时更新；直通卡/前 20 自动标记 |
| 发奖金 | 奖金管理 → 核算单生成 → 现场发放登记 → 导出对账 |
| 总决赛组织 | 晋级管理 → 资格名单（直通+积分前 20）→ 调整确认 → 导出 → （可选）发布资格查询 |
| 争议对账 | 订单管理 → 勾选「显示已取消」→ 全量订单导出；操作日志留痕佐证 |

## 13. 与小程序端的功能对应关系

| 小程序端 | 数据来源/管理入口 |
|---|---|
| 赛事列表 / 赛事详情（含名额、倒计时、时间线） | 后台「赛事管理」创建与发布；名额调整/关闭组别即时生效 |
| 报名/支付/订单状态 | 订单中心全量管理；无待支付状态，取消单仅后台留档 |
| 退款（联系客服） | 客服工单 → 退款工单人工处理 |
| 候补（提交/取消） | 候补管理队列与通知 |
| 资料上传（截止只读） | 资料催收监控；截止时间由赛事时间线控制 |
| 排行榜 / 选手积分详情 / 机构年度榜 / 规则说明 | 榜单中心：成绩录入 → 积分计算 → 榜单发布；纯只读展示 |
| 我的报名（含已退款） | 订单状态机驱动；后台订单详情为管理视图 |
| 关注公众号 | 内容管理-公众号配置 |
