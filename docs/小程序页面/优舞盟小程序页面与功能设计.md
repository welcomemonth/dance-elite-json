# 优舞盟小程序 — 页面与功能设计（不含 UI 视觉）

> 依据：《优舞盟报名功能.md》（报名/支付/候补/资料规则）、《国舞菁英独舞冠军赛FAQ.md》（赛制/榜单/积分/奖项规则）。
> 本文只描述**页面结构、功能点、按钮与用户操作流**，不涉及颜色、样式等视觉设计。

---

## 0. 全局结构与导航

### 0.1 底部 Tab 栏（3 个）

| 位置 | Tab | 说明 |
|---|---|---|
| 左 | 赛事列表 | 浏览赛事、报名、候补 |
| 中 | 排行榜 | **居中且入口明显大于两侧**；榜单/积分模块，与报名系统**无任何数据关联** |
| 右 | 我的 | 报名记录、资料上传、候补、联系客服 |

- 中间 Tab 的视觉尺寸大于左右两个（图标更大/带强调），但交互逻辑与常规 Tab 一致：点击切换页面，当前页再次点击不刷新。
- 所有二级页面（赛事详情、报名表单、榜单详情等）**不显示 Tab 栏**，顶部提供返回按钮。
- **无全局悬浮客服按钮**。客服入口仍按业务场景保留：报名流程中「无大陆身份证号」弹窗内提供「联系客服」按钮，「我的」页提供「联系我们」入口；均拉起微信小程序原生客服会话，用于：退款诉求登记、无大陆身份证号报名、其他特殊情况。

### 0.2 登录态

- 首次打开小程序：微信静默登录（无感，不弹授权框），自动创建/匹配账号；同一微信再次进入必能找到自己的报名记录。
- 「我的」页提供**可选**的「绑定手机号」入口，绑定后报名资料中的电话可一键带出。
- 不绑定手机号不影响任何功能。

## 1. Tab 一：赛事列表

### 1.1 页面布局

1. **顶部标题栏**：页面标题「赛事列表」。
2. **状态筛选栏**（横向可滑动标签）：
   - 全部 / 报名中 / 即将开始 / 报名截止 / 已结束
   - 默认选中「全部」；切换标签即刷新列表。
3. **赛事卡片列表**（纵向滚动，支持下拉刷新、上拉加载更多）：

   每张卡片展示：
   - 赛事名称
   - 赛事级别标签：甲级赛 / 超级赛 / 年度总决赛
   - 举办城市 + 比赛日期
   - 报名费：「¥980/人」「¥1680/人」「总决赛免费」
   - 报名状态标签：报名中（含截止倒计时）/ 未开始（含开始时间）/ 已截止 / 已结束
   - 各组别报名热度（可选展示）：如「U11 古典舞 仅剩 3 席」
   - 卡片整卡可点击 → 进入赛事详情。

4. **空态**：无赛事时展示「暂无赛事，敬请期待」。

### 1.2 用户操作

| 操作 | 结果 |
|---|---|
| 点击状态标签 | 按状态过滤列表 |
| 下拉 | 刷新列表 |
| 点击赛事卡片 | 进入该赛事详情页 |

## 2. 赛事详情页

### 2.1 页面布局（自上而下）

1. **顶部栏**：返回按钮 + 赛事名称。
2. **赛事头图/标题区**：
   - 赛事名称、级别（甲级赛/超级赛）、举办城市、比赛日期、比赛地点。
3. **报名状态区**：
   - 当前状态 + 关键时间倒计时（如「距截止报名还有 5 天」）。
   - 状态为「未开始」时显示报名开始时间。
4. **赛事时间线**（横向或纵向时间轴，5 个节点）：
   - 报名开始 → 截止报名 → 抽签 → 核对舞蹈音频（资料上传最终期限）→ 开始比赛
   - 已过节点置灰，未来节点标注日期。
5. **组别与名额区**：
   - 三个年龄组 U11 / U13 / U15（标注出生年份范围：U11 2016–2018、U13 2014–2015、U15 2012–2013，以 2027-01-01 为年龄计算截止日）。
   - 每个组别展示：名额总数、已报人数、剩余名额；满员组别显示「已满」。
6. **费用与规则区**：
   - 报名费（按赛事统一定价）。
   - 退费政策说明（抽签前可无偿退赛；抽签后个人原因退赛扣除 50%；伤病凭医院诊断证明可顺延不扣费；退款须联系客服，由管理员后台人工处理，原路退回）。
   - 作品时长要求（≤3 分钟）。
   - 比赛流程说明（常规赛 → 20% 晋级决赛 → 决赛 → 当天颁奖）。
7. **荣誉与奖金区**（可折叠）：
   - 各级别赛事奖项设置（冠军/亚军/季军/菁英舞者/特金奖/金奖/银奖）。
   - 奖金规则（甲级赛榜单第一名 2000/1000 元；超级赛前两名 3000/1500 或 2000/1000 元；总决赛前 8 名；机构奖金）。
8. **底部固定操作栏**（随状态变化）：

| 赛事状态 | 底部按钮 |
|---|---|
| 报名中 | 「立即报名」 |
| 未开始 | 「暂未开始报名」置灰，不可点 |
| 已截止/已结束 | 「报名已截止」置灰，不可点 |

### 2.2 用户操作

| 操作 | 结果 |
|---|---|
| 点击返回 | 返回赛事列表，保留列表滚动位置 |
| 点击「立即报名」 | 进入报名表单页 |
| 点击折叠区 | 展开/收起规则与荣誉详情 |

## 3. 报名流程（报名表单 → 支付）

> 核心规则：同一赛事一人（同一身份证）**只能报 1 个组别**（组别由身份证自动判定，不可手选），可报**多个舞种**（古典舞、民族民间舞，分开报名各自成单）；不支持批量代报。

### 3.1 报名表单页

**页面结构：**

1. **顶部栏**：返回 + 标题「填写报名信息」；下方展示赛事名称、级别、比赛日期（防止误报）。
2. **选手信息区**（必填）：
   - 选手姓名（手填）。
   - 身份证号（手填，加密存储）。
   - 机构名称（选填，手填）。
   - 若该微信下有历史报名记录：提供「从历史报名中选择选手」快捷入口，选中后自动带出姓名、身份证号、机构。
3. **组别判定区**（只读展示）：
   - 填写身份证号后自动解析并显示判定结果：「依据身份证号，所属组别：U13（2014–2015 年出生）」。
   - 判定逻辑：以 2027-01-01 为截止日，U11=2016~2018 出生、U13=2014~2015 出生、U15=2012~2013 出生；不在任何区间内即为不符合。
4. **舞种选择区**：
   - 两个单选项：古典舞 / 民族民间舞。
   - 已报过的舞种置灰并标注「已报名」。
5. **底部固定栏**：「提交并支付 ¥xxx」按钮。

**提交时的校验流程（按顺序，任一不通过即弹提示并停留在本页）：**

| 步骤 | 校验 | 不通过时的处理 |
|---|---|---|
| 1 | 是否填写大陆身份证号 | 无身份证号（国际友人等）：弹窗提示「您暂无中国大陆身份证号，无法在线报名，请点击联系客服人工处理」，弹窗内提供「联系客服」「返回」两个按钮（均拉起微信小程序原生客服会话） |
| 2 | 身份证号格式是否合法 | 提示「身份证号不正确，请检查后重试」 |
| 3 | 出生年月是否匹配 U11/U13/U15 | 提示「该选手不符合本次赛事年龄要求（U11/U13/U15），无法报名」，确认后返回赛事列表 |
| 4 | 该身份证在本赛事该组别是否已有**有效报名**（已支付或退款处理中） | 提示「您已报名该赛事的 U13 组别（古典舞），同一赛事一人只能报名一个组别；可为该组别新增另一舞种的报名」，确认后返回 |
| 5 | 所选舞种是否已报过 | 提示「该舞种已报名，请勿重复提交」 |
| 6 | 该组别该舞种名额是否已满 | 进入候补流程（见 3.3），不走支付 |
| 7 | 全部通过 | 创建订单并**立即拉起微信支付** |

### 3.2 微信支付与结果

- 点击「提交并支付」→ 后端创建订单（终态只有：已支付 / 已取消，**不存在待支付状态**；已取消订单仅后台留档备查）→ 直接拉起微信支付收银台。
- **支付成功**：跳转「报名成功页」：
  - 展示赛事、组别、舞种、订单号、金额。
  - 按钮1：「上传参赛资料」（→ 资料上传页，见 5.3）。
  - 按钮2：「查看我的报名」（→ 我的-报名详情）。
  - 提示文案：「资料可在『核对舞蹈音频』时间前随时补充和修改，不上传不影响参赛」。
- **支付失败 / 用户取消 / 关闭收银台 / 返回**：订单**立即取消并消失**，名额即时释放；该订单**不在小程序端任何页面展示**（仅后台留档对账）。Toast 提示「支付未完成，报名未成功」后返回赛事详情页；用户可立即重新发起报名（重新走一遍校验）。
- 全局规则：取消后重新报名无任何等待/超时限制。

### 3.3 候补流程（名额满时）

**候补表单页**（由校验步骤 6 进入）：

- 顶部说明：「该组别（U13·古典舞）名额已满，您可以提交候补信息；若有选手退赛，工作人员将按顺序电话联系您。」
- 表单字段（均预填报名时已填内容）：
  - 选手姓名（必填）
  - 身份证号（必填）
  - 机构名称（选填）
  - 组别与舞种（只读，即所报内容）
  - **联系电话（必填，未绑定手机号时强制手填）**
- 底部按钮：「提交候补」。
- 提交成功 → 「候补成功页」：说明候补规则（有退赛时管理员人工电话通知、候补不收费、确认后需重新走正常报名支付流程），按钮「返回赛事列表」。
- 候补记录可在「我的-我的候补」中查看与取消候补（取消候补仅移出队列，不涉及退款）。

## 4. Tab 二：排行榜（中间大入口）

> 数据全部来自后端接口，小程序只读展示。页面所有选项（年龄段、舞种、晋级名额、Banner 文案）均从配置接口动态获取，不写死。
>
> **接口对照：**
>
> | 用途 | 接口 | 关键字段 |
> |---|---|---|
> | Banner 文案、年龄段/舞种选项、晋级名额、更新时间 | `GET /api/v1/config` | `season / title / subtitle / levels[] / danceStyles[] / advanceQuota / updatedAt` |
> | 榜单数据（直通榜 + 积分榜） | `GET /api/v1/ranking?level=&dance_type=` | `Board{direct[], ranking[]}` |
> | 机构榜 | `GET /api/v1/institution/ranking` | `institutions[]{name, points}` |
> | 选手详情（4.2 页） | `GET /api/v1/dancer/:id` | `Dancer`（id 按榜单独立） |

### 4.1 榜单首页

**页面布局（自上而下）：**

1. **顶部 Banner**：展示赛事榜单标题与赛季信息（`title` / `subtitle` / `season`，如「2026 赛季」）。
   - 纯展示，**不提供赛季切换**（当前为单赛季；接口数据仅含当前赛季）。
2. **一级分类 Tab**（横向排列）：
   - 年龄段按钮，选项来自 `config.levels`（如 U11 / U13 / U15），当前选中项高亮。
   - 排列末尾为「机构排名」入口按钮，样式与年龄段按钮区分。
3. **二级分类 Tab**：
   - 舞种切换，选项来自 `config.danceStyles`（古典舞 / 民族民间舞）。
   - 当前选中项以下划线指示。
   - 选中「机构排名」时，本 Tab 整体隐藏。
4. **搜索框**：
   - 全宽输入框，左侧搜索图标；选手模式下占位文字「搜索选手姓名」，机构模式下为「搜索机构名称」。
   - 输入即对当前已加载列表做本地过滤（接口一次性返回整榜，无需额外请求）；无结果显示空态「未找到相关选手/机构」。
5. **直通榜区域**（仅选手模式，居中标题「直通榜」）：
   - 列表形式，每项包含：
     - 左侧：圆形头像 + 直通标识小角标。
     - 中间：选手姓名（只显示姓名）。
     - 中间靠右侧：奖项/奖金文字（罗列出选手的所有奖项，如「上海甲级赛 · 冠军 ¥2000」）+
     - 最右侧： 「直通晋级」。
   - 展示全部直通选手。
   - 该榜单下无直通选手时，显示暂无直通选手（一般也不会有这种情况）。
6. **正式积分榜区域**（仅选手模式）：
   - 表头一行：排名 ｜ 选手 ｜ 变化 ｜ 总积分。
   - 列表按 `rank` 升序，每行：
     - 左侧：排名数字（前 3 名带特殊排名标识）+ 圆形头像。
     - 中间：选手姓名。
     - 右侧：变化箭头 + 总积分数值。变化规则：`rankChange > 0` 显示上升箭头；`< 0` 显示下降箭头；`prevRank = 0`（上期不在榜）显示「新上榜」。
   - **「晋级区」分区标题**：插在第 `config.advanceQuota` 名之后，作为分割线/分区标题；线上方即积分晋级名额内（除直通选手外，按积分前 `advanceQuota` 名晋级年度总决赛），线下方为区外。
   - 榜单底部小字展示「榜单更新于 {updatedAt}」。
7. **机构排名视图**（点击一级 Tab「机构排名」后，替换上方 5、6 区域）：
   - 排名列表：排名、机构名称、年度总积分，前 3 名带特殊排名标识。
   - 荣誉说明区：第 1–3 名「年度菁英机构奖」+ 10000 元奖金；第 4–10 名「年度十佳机构奖」。
   - 作为本页内的视图状态切换，不做页面跳转。

**加载与默认态：**

- 进入页面：默认选中 `config.levels[0]` + `config.danceStyles[0]`，请求一次 `/ranking` 同时渲染直通榜与积分榜。
- 切换年龄段 / 舞种：重新请求 `/ranking`（参数为当前选中组合），两个区域一并刷新。
- 接口失败：Toast「榜单加载失败，请稍后重试」并提供重试按钮；当前无数据时展示空态。

**用户操作：**

| 操作 | 结果 |
|---|---|
| 切换年龄段按钮 | 重新加载对应榜单（直通榜 + 积分榜） |
| 切换舞种 Tab | 重新加载对应榜单 |
| 点击「机构排名」 | 切换为机构榜视图；点击任一年龄段按钮即切回选手榜 |
| 输入搜索关键字 | 本地实时过滤当前视图列表（直通榜、积分榜或机构榜） |
| 点击直通榜行 / 「直通晋级」按钮 | 进入该选手积分详情页（见 4.2，使用该行 `id`） |
| 点击积分榜行 | 进入该选手积分详情页（见 4.2） |
| 点击机构榜行 | 无跳转（暂无机构详情接口） |

### 4.2 选手积分详情页

- 顶部：选手姓名、组别、舞种、当前排名、总积分。
- 积分构成：展示计入排名的场次（**取本年度积分最高的 3 场，不足 3 场按实际计**），每场列出：赛事名称、日期、级别（甲级/超级）、奖项、该场积分。
- 参赛历史：本年度全部场次的成绩列表。
- 荣誉展示：该选手获得的奖项（冠军/亚军/季军/菁英舞者/特金奖/金奖/银奖等）与晋级情况（总决赛直通卡/积分前 20 晋级）。
- 入口：积分榜行、直通榜行/「直通晋级」按钮均可进入；`dancer` 接口的 `id` 按榜单独立，直接透传列表行中的 `id` 即可。
- 无排名选手（未上榜）不提供此页入口。

### 4.3 积分规则说明页

- 纯文本说明页，内容来自 FAQ：
  - 积分按名次和参赛人数动态计算；同等奖项下超级赛积分高于甲级赛。
  - 排名依据为本年度积分最高的 3 场积分赛，每场积分赛结束后实时更新。
  - 晋级规则：甲级赛第一名、超级赛前两名直通年度总决赛；其余按各榜单全年积分前 20 获得总决赛资格。
  - 总决赛荣誉体系（MVP/全国总冠军/八强/十六强/四十强）与奖金分配。
- 入口：榜单首页 Banner 区/列表底部「积分规则说明」链接、「我的-规则说明」。

## 5. Tab 三：我的

### 5.1 我的主页

**页面布局（自上而下）：**

1. **用户信息区**：
   - 微信头像、微信昵称。
   - 「绑定手机号」入口：未绑定显示「未绑定手机号 >」，点击触发微信手机号授权绑定；已绑定显示脱敏手机号（138****5678）。
2. **资料待办提醒卡**（**有已支付但未传齐资料的报名时显示，置顶**）：
   - 内容：「您有 X 条报名的参赛资料未传齐」（如「2026 上海甲级赛 · U13 古典舞 · 资料待补充」）。
   - 右侧按钮「去上传」→ 直接进入对应报名的资料编辑页。
   - 多条未传齐时点击进入「我的报名」列表，由用户选择。
   - 全部资料传齐或无有效报名时，此卡不显示。
3. **功能入口列表**，分两块展示（每行带图标 + 文字 + 右箭头）：

   **第一块：我的赛事**
   - 我的报名（角标显示有效报名数量；含退款处理中/已退款记录）
   - 我的候补（角标显示候补中数量）

   **第二块：其他**
   - 关注公众号（见 5.5）
   - 联系我们（拉起微信小程序原生客服会话，用于退款诉求登记、无身份证号报名等特殊情况）
   - 关于优舞盟 / 赛事规则说明（跳规则说明页）

### 5.2 我的报名列表页

- 列表项 = 一张有效报名（订单状态为：已支付 / 待补充资料 / 资料已齐 / 退款处理中 / 已退款）。
- **已取消（未支付成功）的订单不在此展示**（仅后台留档）。
- 每项展示：赛事名称 + 级别、比赛日期、组别 + 舞种、选手姓名、报名状态标签、资料完成度（如「资料待补充 3 项」）。
- 状态标签与说明：

| 状态 | 展示标签 | 可执行操作 |
|---|---|---|
| 已支付（资料未传齐） | 待补充资料 | 查看详情、上传资料 |
| 已支付（资料已传齐） | 报名成功 | 查看详情、修改资料 |
| 退款处理中 | 退款处理中 | 仅查看详情 |
| 已退款 | 已退款 | 查看详情（仍可查看当时填写的报名信息与资料） |

- 点击列表项 → 报名详情页。
- 退款入口说明：小程序端**无自助退款按钮**，退款统一通过「我的-联系我们」找客服登记，由管理员后台处理。

### 5.3 报名详情页

**页面布局：**

1. **报名状态卡**：状态标签 + 状态说明文案：
   - 待补充资料：「请在 X 月 X 日（核对舞蹈音频时间）前上传资料；不上传不影响参赛」+「去上传资料」按钮。
   - 报名成功：「资料已传齐，祝您比赛顺利」（截止前仍可修改资料）。
   - 退款处理中：「客服已登记您的退款申请，请等待工作人员处理，结果将通过客服会话告知」。
   - 已退款：「该报名已退款，费用原路退回，到账时间以支付渠道为准」。
2. **报名信息卡**（只读）：赛事、组别、舞种、选手姓名、机构、订单号、支付金额、支付时间。
3. **参赛资料卡**（可编辑，截止前）/ 只读（截止后）：
   - 资料项清单，每项标注「已上传 ✓ / 未上传」及已传内容的摘要（文件名/文本前几字）：
     | 资料项 | 必填性 | 限制 |
     |---|---|---|
     | 证件照 | 核心（不上传不影响参赛） | png/jpg，≤10MB |
     | 舞蹈音频 | 核心 | mp3，≤100MB，≤4 分钟 |
     | 节目名称 | 核心 | 文本 |
     | 指导教师 | 可选 | 文本 |
     | 联系电话 | 核心 | 手机号格式 |
     | 快递地址 | 可选 | 文本（证书/奖牌邮寄） |
     | 作品说明 | 可选 | 多行文本 |
     | 特殊要求 | 可选 | 多行文本（如道具需求） |
   - 每项右侧「上传/修改」入口。
   - 顶部提示条：「资料请在『核对舞蹈音频』时间（X 月 X 日）前上传；不上传不影响参赛。」
4. **底部操作区**：
   - 「上传/修改资料」主按钮（→ 资料编辑页）。
   - 「联系客服」次按钮（退款、改信息、特殊情况等诉求入口，拉起微信小程序原生客服会话；小程序端无自助退款按钮）。

**重复上传/更新规则：**
- 在「核对舞蹈音频」截止时间之前，**所有已上传的资料项均可重复上传/修改，不限次数**，每次新上传直接覆盖旧内容，以最后一次为准。
- 到达截止时间后，资料卡整体变为只读，仅可查看，不可再修改。

### 5.4 资料编辑页（表单）

- 逐项编辑：
  - 证件照：「选择图片」（已上传时显示当前照片缩略图 + 「重新选择」）→ 调起相册/拍照；选择后立即校验格式与大小，不合法弹提示且不保存。
  - 舞蹈音频：「选择音频」（已上传时显示当前文件名 + 播放预览 + 「重新选择」/「删除」）→ 调起文件选择；校验 mp3 格式、≤100MB、时长 ≤4 分钟。
  - 其余文本项：普通输入框/多行输入框（已填内容回填，可修改），电话校验 11 位手机号。
  - 敏感内容自动限制（关键词过滤），**无人工审核环节**。
- 支持分次提交：每次保存单项即生效，不要求一次性传齐；**截止前可反复修改**。
- 底部「保存」按钮；保存成功返回详情页并刷新资料完成度。

### 5.5 关注公众号

- 点击「关注公众号」入口：
  - 方案一（有公众号时）：展示公众号二维码图片 + 提示文案「长按识别二维码，关注『优舞盟』公众号，获取赛事资讯与成绩通知」，支持长按识别。
  - 方案二：若小程序与公众号已关联，可直接通过客服会话引导关注。
- 纯展示页，无其他操作。

### 5.6 联系我们

- 拉起微信小程序原生客服会话。
- 客服侧处理范围：退款诉求登记（→ 管理员后台人工处理）、无身份证号报名登记、候补咨询、其他异常问题。
- 用户侧无表单，直接进入会话。

## 6. 关键交互与异常场景汇总

| 场景 | 页面表现 |
|---|---|
| 打开小程序未登录 | 静默登录，无感知；失败时 Toast「登录失败请重试」并提供重试 |
| 重复点击报名/支付按钮 | 按钮置灰防重复提交；后端幂等校验 |
| 支付过程中退出小程序/断网 | 订单按支付结果回调落库：成功则报名成功，失败/未知则取消；用户重新进入后在「我的-我的报名」可核对（未支付订单不出现） |
| 名额并发抢报 | 以服务端校验为准；仅一人成功下单，其余引导候补 |
| 身份证号已用于其他微信报名 | 以身份证号判重：提示「该选手已报名该赛事该组别」 |
| 赛事中途被管理员关闭组别 | 赛事详情与报名按钮即时置灰；已支付报名不受影响 |
| 未到报名开始时间 | 详情页按钮置灰「X 月 X 日开始报名」 |
| 上传资料超过截止时间 | 资料卡只读，提示「资料上传已截止」 |
| 已退款 | 报名保留在「我的报名」中，状态「已退款」，详情页展示退款说明 |
